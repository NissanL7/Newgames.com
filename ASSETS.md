# Demo asset sources

The application code and interface are original to this project. Demo thumbnails were obtained through image search from the following public pages; ownership remains with the respective creators.

- Big Buck Bunny poster: https://demo.cinevee.com/tears-of-steel
- Sintel and Tears of Steel stills: https://4kmedia.org/big-buck-bunny-4k-demo/
- Elephants Dream still: https://fr.wikipedia.org/wiki/Elephants_Dream
- Canyon and island aerials: https://pixabay.com/videos/search/cinematic%20travel/ and https://pixabay.com/videos/search/cinematic%20mountains/
- Nature template still: https://www.capcut.com/explore/mountain-video-template/7520711868331182098
- Studio image: https://www.reddit.com/r/audioengineering/comments/r4claw/tiny_desk_concerts_how_they_do_it/
- Music artwork: https://create.vista.com/templates/youtube-thumbnails/music
- Music vlogging artwork: https://diymusicbiz.com/vlogging-for-musicians-part-1/
- Desk image: https://dslrvideoshooter.com/the-ultimate-video-desk

Catalog video playback uses the publicly accessible sample files under `https://storage.googleapis.com/gtv-videos-bucket/sample/`. These remote videos are not bundled into the repository or cached by the service worker.

User-selected uploads remain in the browser's IndexedDB and are not transmitted to these services.

# Asset notes

## Original project assets

- `public/assets/icons/icon.svg`: original Savr arrow mark.
- `public/assets/icons/icon-192.png` and `icon-512.png`: raster versions generated locally from the same geometric design.
- `public/assets/sample-poster.svg`: original vector poster created for this reconstruction.
- `public/assets/creator-sample.webm`: original, locally generated four-second motion study; no third-party footage or audio.

## Runtime media

- YouTube thumbnails are derived from the user-supplied public video ID or returned by YouTube oEmbed. They remain remote third-party media and are not bundled.
- Direct media remains at its user-supplied source. Savr does not mirror or republish it.
- Inter Variable is bundled through the npm `@fontsource-variable/inter` package under its included font license.
- Interface icons are from `lucide-react` under its included ISC license.
